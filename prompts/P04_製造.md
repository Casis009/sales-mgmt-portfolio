```text

poc/ 를 내 PC에서 실행해 볼게. 내가 에러 메시지를 붙이면 고쳐 주고,
결과를 docs/ja/03_詳細設計/01_技術検証結果報告書.md(+ 한국어판)에 반영해서 1.0판으로 만들어줘.
문제가 있으면 보고서 4장의 대안을 적용하고, 영향받는 설계서를 개정해줘.
```

## 2단계 이후: 기능 구현(반복)

아래 「대상」만 바꿔서 같은 프롬프트로 반복하세요.
- 2단계: 共通(로그인·권한·조작 로그) + マスタ(商品・倉庫・取引先) → `v0.1`
- 3단계: 在庫(入出庫・在庫照会・倉庫間移動・棚卸) → `v0.2`
- 4단계: 購買(発注・承認・入荷) → `v0.3`
- 5단계: 販売(受注・出荷) → `v0.4`
- 6단계: 請求(締め処理・請求書PDF) + バッチ(発注点・月次集計) → `v0.5`

```text
CLAUDE.md, PROGRESS.md를 읽고 04_製造의 【대상: 여기에 기입】을 구현해줘.
- 詳細設計 대로 구현하고, 설계와 다르게 한 부분은 설계서를 고치고 改訂履歴에 남겨줘
- 단위 테스트(JUnit)도 함께 작성
- docs/ja/04_製造/02_コードレビュー記録票.md에 셀프 리뷰 결과 추가
- 교육자료 docs/guide/04-N_【대상】_구현포인트.md: 코드에서 꼭 이해해야 할 부분
- PROGRESS.md 갱신, 커밋 메시지·태그 제안
```
