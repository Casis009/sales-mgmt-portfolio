# 販売管理システム（ポートフォリオ）

照明器具卸売業（架空）向けの販売管理システムを、**要件定義から運用まで**一貫して構築するポートフォリオです。

> ※ 本プロジェクトはポートフォリオ用の架空案件です。

## 対象業務
在庫管理（入出庫・棚卸） / 購買管理（発注・承認・入荷） / 販売管理（受注・出荷・請求書発行）

## 技術スタック（予定）
Java 21 / Spring Boot 3 / Spring Security / MyBatis / Thymeleaf / PostgreSQL / Flyway / Spring Batch / JUnit5 / Testcontainers / Playwright / Docker / GitHub Actions / Oracle Cloud

## ドキュメント構成

| フォルダ | 内容 |
