## 2. BAT-01 発注点チェックバッチ

| 項目 | 内容 |
|---|---|
| 概要 | 発注点を下回った「商品 × 倉庫」を抽出し、発注アラートを作成する（BR-27） |
| 入力 | 在庫、商品倉庫設定、商品、発注、発注明細 |
| 出力 | 発注アラート（全件を削除してから作成） |
| パラメータ | 実行日（省略時はシステム日付） |

### 処理内容

1. 発注アラートを全件削除する。
2. 商品倉庫設定が存在し、商品・倉庫がともに有効な「商品 × 倉庫」について、以下を求める。
   - 有効在庫数 ＝ 現在庫数 − 引当数（在庫の行がない場合は 0）
   - 発注残数 ＝ ステータスが「承認待ち・承認済・一部入荷」の発注の（発注数量 − 入荷済数量）の合計
3. 「有効在庫数 ＋ 発注残数 ≦ 発注点」かつ「発注点 ＞ 0」のものを発注アラートに登録する。
4. 処理件数（対象件数・アラート件数）をログに出力する。

### 異常時・再実行

| 項目 | 内容 |
|---|---|
| 異常終了時 | 処理全体をロールバックし（前日のアラートが残る）、監視から開発担当へ通知する |
| 再実行 | そのまま再実行できる（何度実行しても結果は同じ） |
| 業務への影響 | 当日朝のアラートが前日時点の内容となる。在庫照会画面で発注点以下の商品を確認できるため、業務は継続可能 |

## 3. BAT-02 月次在庫集計バッチ

| 項目 | 内容 |
|---|---|
| 概要 | 前月末時点の在庫数を「商品 × 倉庫」ごとに月次在庫へ保存する |
| 入力 | 在庫 |
| 出力 | 月次在庫（対象年月の行を削除してから作成） |
| パラメータ | 対象年月（省略時は実行日の前月） |

### 処理内容

1. 対象年月の月次在庫を削除する。
2. 在庫の全行について、現在庫数・引当数を対象年月の月次在庫として登録する。
3. 処理件数をログに出力する。

### 前提・異常時・再実行

| 項目 | 内容 |
|---|---|
| 前提 | 月末の営業終了後から翌月1日の営業開始前までに在庫が動かないこと（運用時間外のため）。バッチ実行時点の在庫数を月末在庫とみなす |
| 異常終了時 | 処理全体をロールバックし、監視から開発担当へ通知する |
| 再実行 | 翌月1日の営業開始（8:00）前であれば、そのまま再実行できる。営業開始後に再実行すると当日の入出庫が含まれるため、その場合は入出庫履歴から月末時点の在庫数を逆算する手順（運用手順書に定める）で作成する |

## 4. BAT-03 請求締めバッチ

| 項目 | 内容 |
|---|---|
| 概要 | 指定した締日までの未請求の出荷を得意先ごとに集計し、請求・請求明細を作成する（BR-31～34） |
| 入力 | 出荷、出荷明細、取引先、商品、消費税率 |
| 出力 | 請求、請求明細、出荷（請求IDを設定） |
| パラメータ | 締日、締日区分、得意先ID（任意）、実行者のユーザーID |

### 処理内容

1. 対象の得意先（締日区分が一致し、締日以前の未請求の出荷がある得意先）を取得する。
2. 得意先ごとに、以下を1トランザクションで行う。
   1. 対象の出荷（未請求・出荷済・出荷日が締日以前）を取得する。
   2. 出荷明細を税区分ごとに合計し、消費税額を計算する（税率ごとに1回、1円未満切り捨て）。
   3. 請求番号を採番し、請求・請求明細を登録する。
   4. 対象の出荷に請求IDを設定する。
3. 作成件数を実行結果として記録する。

締め対象の条件・算出方法の詳細は「画面設計書 SCR-501」の5章・6章を参照。

### 異常時・再実行

| 項目 | 内容 |
|---|---|
| コミット単位 | 得意先1社ごと |
| 異常終了時 | エラーとなった得意先の処理のみロールバックし、バッチを異常終了とする。処理済みの得意先の請求は有効とする |
| 再実行 | 同じパラメータでそのまま再実行できる。請求済みの出荷は対象外となるため、未処理の得意先のみが処理される |
| 二重起動の防止 | 実行中の請求締めバッチがある場合は起動しない（E-052） |

## 5. バッチ共通仕様

| No | 項目 | 仕様 |
|---|---|---|
| 1 | 実行基盤 | Spring Batch。アプリケーション内のスケジューラまたは画面から起動する |
| 2 | 実行履歴 | Spring Batch の実行管理テーブルに、開始・終了日時、結果、処理件数を記録する |
| 3 | 操作ログ | 開始・終了を操作ログ（操作種別：BATCH）に記録する |
| 4 | ログ出力 | 開始・終了・処理件数・エラー内容をアプリケーションログに出力する |
| 5 | 監視 | 異常終了、および所定の時刻までに終了しない場合に通知する（NF-15） |
| 6 | オンラインとの関係 | BAT-01・BAT-02 は運用時間外に実行する。BAT-03 は運用時間内に実行するが、出荷登録と競合しても整合性が保たれるようにする（詳細設計で定める） |
