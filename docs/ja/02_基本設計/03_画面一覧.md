## 5. 画面共通仕様

### 5.1 レイアウト

```
+--------------------------------------------------------------------------+
| 販売管理システム            [メニュー]        山本 太郎（物流担当） [ログアウト] |  ← ヘッダー
+--------------------------------------------------------------------------+
| 在庫管理 > 在庫照会                                                       |  ← パンくず
+--------------------------------------------------------------------------+
| （メッセージ表示欄：情報＝緑、警告＝黄、エラー＝赤）                        |
+--------------------------------------------------------------------------+
|                                                                          |
|  （各画面の内容）                                                         |
|                                                                          |
+--------------------------------------------------------------------------+
```

### 5.2 共通ルール

| No | 項目 | 仕様 |
|---|---|---|
| 1 | 一覧画面 | 検索条件＋検索結果の構成。1ページ50件でページング表示する（NF-07）。初期表示では検索しない（在庫照会・発注アラートを除く） |
| 2 | 並び順 | 伝票の一覧は伝票日付の降順、マスタの一覧はコードの昇順を初期値とする |
| 3 | 必須項目 | ラベルに「※」を表示する |
| 4 | 入力チェック | サーバー側で必ず実施する。エラー時は入力内容を保持したまま同じ画面を再表示し、項目の下にエラーメッセージを表示する |
| 5 | 二重送信防止 | 登録・更新ボタンは押下後に非活性にする。サーバー側でもトークンにより二重登録を防ぐ |
| 6 | 排他制御 | 伝票・マスタの更新は楽観的排他とする。他のユーザーが先に更新していた場合はエラー（E-020）とする |
| 7 | 数値の表示 | 数量・金額は3桁区切り、右寄せ。金額は円単位（小数なし） |
| 8 | 日付の表示・入力 | `yyyy/MM/dd` 形式。入力はカレンダーから選択できる |
| 9 | 確認ダイアログ | 取消・承認・差戻し・確定・締め処理の実行前に確認ダイアログを表示する |
| 10 | 権限のないボタン | 表示しない（URL を直接指定した場合はサーバー側でエラー E-012 とする） |
| 11 | セッション切れ | ログイン画面へ遷移し、E-013 を表示する |
| 12 | マスタの削除 | 物理削除は行わず、「無効」に変更する。無効のマスタは新規の伝票で選択できない |

### 5.3 個別の設計書を作成しない画面の主な仕様

| 画面ID | 主な仕様 |
|---|---|
| SCR-002 | 権限に応じたメニューを表示する。ダッシュボードとして「発注アラート件数（物）」「承認待ち件数（承）」「未出荷受注件数（物・営）」を表示し、クリックで各一覧へ遷移する |
| SCR-003 | 現在のパスワード、新しいパスワード、確認用を入力する。NF-24 の条件を満たさない場合は E-015 |
| SCR-012 | ログインID、氏名、所属、権限（複数選択）、有効／無効、ロック解除。新規登録時は初期パスワードを設定する。自分自身の無効化・自分のシステム管理者権限の削除は不可（E-018）。変更の結果、有効なシステム管理者が0人になる場合も不可（E-019） |
| SCR-013 | 検索条件：操作日時（範囲）、ユーザー、操作種別、対象。照会のみ（変更・削除不可、NF-31） |
| SCR-102 | 商品情報に加え、倉庫ごとの発注点・標準発注数を入力する欄を設ける（F-104） |
| SCR-122 | 得意先フラグ・仕入先フラグを選択する。得意先の場合は締日・支払条件を必須とする |
| SCR-202 | 検索条件：期間、倉庫、商品、入出庫区分。増減数・変動後在庫数・関連伝票番号・操作者を表示する |
| SCR-203 | 倉庫、商品、調整区分（増／減）、数量、理由（必須）を入力する。BR-03、BR-05 を適用する |
| SCR-204 | 移動元倉庫、移動先倉庫、商品、数量を入力する。移動数量は移動元の有効在庫数以下とする |
| SCR-211 | 棚卸の一覧と「棚卸開始」（倉庫・棚卸日を指定）。同じ倉庫で実施中の棚卸がある場合は開始できない（E-034） |
| SCR-212 | 商品コード順に帳簿在庫数を表示し、実棚数・差異理由を入力する。Tab キーで次の行の実棚数へ移動できる（R-06）。「一時保存」と「確定」を設ける。確定時は BR-06 を適用する |
| SCR-304 | 発注明細ごとに発注数・入荷済数・残数を表示し、今回入荷数を入力する。BR-05、BR-26 を適用する |
| SCR-305 | 発注アラートを倉庫・仕入先で絞り込み、選択した商品を発注登録（SCR-302）へ引き継ぐ |
| SCR-401 | 検索条件：受注日（範囲）、得意先、ステータス、担当者。CSV 出力ボタン（F-405） |
| SCR-403 | 受注内容と出荷実績の一覧を表示する。未出荷の場合は「編集」「取消」、一部出荷済みの場合は「残数取消」を表示する（BR-16）。出荷実績の各行に「出荷取消」を表示する（物流担当のみ。未請求かつ残数取消を行っていない受注の出荷に限る。BR-17）。出荷取消時は、対象倉庫が棚卸実施中でないこと（BR-05）を確認し、在庫・引当・出荷済数量を戻して入出庫履歴（区分：出荷取消）を記録する |
| SCR-404 | 未出荷・一部出荷の受注を、倉庫別・納期順に表示する。ブラウザの印刷機能でピッキング用に印刷できるレイアウト（ヘッダー・メニューを除き、チェック欄を付ける）を用意する（D-26）。行から出荷登録（SCR-405）へ遷移する |
| SCR-503 | 請求内容・明細を表示する。「請求書出力」（F-503）、「締め取消」（F-504、未発行のみ） |
