## 1. 検証の目的

技術選定書（第1.1版）で採用した技術のうち、実績が少ない組み合わせ・本プロジェクト固有の条件について、製造開始前に動作を確認し、手戻りのリスクを下げる。

## 4. 問題が見つかった場合の代替案

| No | 想定する問題 | 代替案 | 設計への影響 |
|---|---|---|---|
| P-01 | MyBatis の対応版が Spring Boot 4.1 で動作しない | Spring Boot を 4.0 系の最新パッチに下げる（4.0 系は対応版が提供済み） | 技術選定書のみ |
| P-02 | 日本語が文字化けする、フォントを埋め込めない | ① フォント拡張の設定を見直す ② OpenPDF を直接使用して帳票を出力する | ②の場合は帳票の詳細設計・工数を見直す |
| P-03 | ARM で動作しないライブラリがある | OCI の x86 インスタンス（AMD）を使用する | システム構成図（インスタンス種別）のみ |
| P-04 | GitHub Actions で Testcontainers が動作しない | CI ではワークフローの services で PostgreSQL を起動して接続する | テスト基盤の設定のみ |
| P-05 | 非同期起動・実行状況の取得が想定どおりにできない | 請求締めを同期処理（画面は処理完了まで待つ）とする。5年後の件数でも数十秒の見込み | SCR-501 の実行状況表示、バッチ詳細設計 |
