## 1. 業務用語

| 用語 | 読み | 英語名（物理名に使用） | 説明 |
|---|---|---|---|
| 商品 | しょうひん | product | 顧客が販売する照明器具・LED製品。SKU 単位で管理する |
| 倉庫 | そうこ | warehouse | 在庫を保管する拠点（本社倉庫・北九州倉庫） |
| 取引先 | とりひきさき | partner | 得意先と仕入先の総称。1つの取引先が両方を兼ねることがある |
| 得意先 | とくいさき | customer | 商品の販売先 |
| 仕入先 | しいれさき | supplier | 商品の仕入元 |
| 受注 | じゅちゅう | sales order | 得意先からの注文を受けること、またはその伝票 |
| 出荷 | しゅっか | shipment | 受注に基づき倉庫から商品を出すこと。出荷日を売上計上日とする（出荷基準） |
| 分納 | ぶんのう | partial shipment / partial receiving | 1つの受注・発注を複数回に分けて出荷・入荷すること |
| 受注残 | じゅちゅうざん | sales order backlog | 受注数量のうち、まだ出荷していない数量 |
| 発注 | はっちゅう | purchase order | 仕入先へ商品を注文すること、またはその伝票 |
| 入荷 | にゅうか | receiving | 発注した商品が倉庫に届き、受け入れること |
| 発注残 | はっちゅうざん | on-order quantity | 発注数量のうち、まだ入荷していない数量 |
| 承認 | しょうにん | approval | 承認者が発注内容を確認し、発注を許可すること |
| 差戻し | さしもどし | reject / send back | 承認者が発注を承認せず、申請者に修正を求めること |
| 現在庫数 | げんざいこすう | stock quantity | 倉庫に実際にある数量（帳簿在庫） |
| 引当 | ひきあて | allocation | 受注に対して在庫を確保（予約）すること |
| 引当数 | ひきあてすう | allocated quantity | 受注済みで未出荷の数量の合計 |
| 有効在庫数 | ゆうこうざいこすう | available quantity | 現在庫数 − 引当数。新たな受注に充てられる数量。マイナスの場合は在庫不足を表す |
| 発注点 | はっちゅうてん | reorder point | この数量を下回ったら発注する、という基準の数量 |
| 標準発注数 | ひょうじゅんはっちゅうすう | standard order quantity | 発注アラートで提示する発注数量の目安 |
| 入出庫履歴 | にゅうしゅっこりれき | stock movement | 在庫数量が増減した記録 |
| 在庫調整 | ざいこちょうせい | stock adjustment | 破損・返品・紛失などにより在庫数を手動で増減すること |
| 倉庫間移動 | そうこかんいどう | stock transfer | 倉庫から別の倉庫へ在庫を移すこと |
| 棚卸 | たなおろし | stocktaking | 倉庫の商品を実際に数え、帳簿在庫と照合すること |
| 実棚数 | じつたなすう | actual quantity | 棚卸で実際に数えた数量 |
| 棚卸差異 | たなおろしさい | stocktaking difference | 実棚数 − 帳簿在庫数 |
| 締日 | しめび | closing day | 請求の対象期間を区切る日。得意先ごとに設定する |
| 請求締め | せいきゅうじめ | invoice closing | 締日までの出荷実績を集計し、請求データを確定すること |
| 請求 | せいきゅう | invoice | 得意先へ代金の支払いを求めること、またはその伝票 |
| 適格請求書 | てきかくせいきゅうしょ | qualified invoice | インボイス制度の要件（登録番号、税率ごとの対価の額と消費税額など）を満たす請求書 |
| 端数処理 | はすうしょり | rounding | 消費税額の1円未満の扱い。本システムでは切り捨て |

## 2. システム用語

| 用語 | 説明 |
|---|---|
| マスタ | 商品・倉庫・取引先など、業務の基本となるデータ |
| 伝票 | 受注・出荷・発注・入荷・請求など、取引を記録するデータ。ヘッダと明細で構成する |
| ステータス | 伝票の進行状態（例：承認待ち、出荷完了） |
| 操作ログ | 利用者の操作（誰が・いつ・何を）を記録したデータ |
| バッチ | 利用者の操作によらず、決まった時刻または指示によりまとめて実行する処理 |
| 権限（ロール） | 利用者に付与する役割。利用できる画面・操作を決める |
