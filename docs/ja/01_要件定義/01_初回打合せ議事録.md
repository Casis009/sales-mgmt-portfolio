## 4. 議事内容

### 4.1 背景・目的（田中部長）

- 5年前は取扱商品が300程度だったが、現在は約800SKUまで増えた。
- Excel での管理が限界に来ており、特に「在庫が合わない」ことが一番の悩み。
- 来年4月から新しい仕入先との取引が始まるため、それまでにシステムを稼働させたい。

### 4.2 受注〜出荷（田中部長・山本主任）

- 受注は電話・FAX・メールで受け付け、営業担当が「受注台帳.xlsx」に手入力している。
- 1日の受注件数は平均40件程度（繁忙期の12月・3月は約2倍）。
- 受注台帳を印刷して倉庫に渡し、倉庫側で出荷作業を行う。
- 出荷後、倉庫担当が「在庫表.xlsx」の数量を手で減らしている。
- 在庫がないことに出荷時点で気づくことがあり、顧客への連絡が遅れて失注につながったケースがある。
- 分納（一部だけ先に出荷）は月に数件程度発生する。 → 扱いは確認事項（Q-03）とする。

### 4.3 発注〜入荷（山本主任）

- 在庫表を見て、山本主任が経験をもとに発注数を判断している。
- 発注書は Excel で作成し、田中部長の押印後に FAX で仕入先へ送付している。
- 山本主任が不在の日は発注が止まってしまう（属人化）。
- 入荷時は納品書と発注書を目視で照合し、在庫表に加算している。

### 4.4 在庫・棚卸（山本主任）

- 倉庫は本社倉庫と北九州倉庫の2か所。在庫表は倉庫ごとに別ファイル。
- 倉庫間の移動は月に10件程度あるが、記録が漏れやすい。
- 棚卸は月末に実施。帳簿在庫と実在庫の差異が毎回20〜30品目発生し、原因が追えない。

### 4.5 請求（佐藤様）

- 締日は月末締め。翌月5営業日以内に請求書を発行している。
- 受注台帳から得意先ごとに集計し、Word のテンプレートに転記して請求書を作成している。
- 作成に毎月3日程度かかっている。転記ミスによる再発行も月に数件ある。
- インボイス制度に対応した請求書（登録番号・税率ごとの消費税額の記載）が必要。

### 4.6 システムへの要望・制約

| 区分 | 内容 | 発言者 |
|---|---|---|
| 要望 | 在庫数を倉庫別にリアルタイムで確認したい | 田中部長 |
| 要望 | 在庫が一定数を下回ったら知らせてほしい | 山本主任 |
| 要望 | 発注には部長の承認を必須にしたい（押印の代わり） | 田中部長 |
| 要望 | 請求書をボタン一つで作成したい（PDF） | 佐藤様 |
| 要望 | 誰がいつデータを変更したか記録を残したい | 田中部長 |
| 制約 | 来年4月までに稼働させたい | 田中部長 |
| 制約 | 会計ソフトは現行のものを継続利用する | 佐藤様 |
| 制約 | 既存の Excel データ（商品・取引先・在庫）を移行したい | 山本主任 |
