## 2. BAT-01 발주점 체크 배치

| 항목 | 내용 |
|---|---|
| 개요 | 발주점 아래로 내려간 「상품 × 창고」를 추출해 발주 알림 생성(BR-27) |
| 입력 | 재고, 상품 창고 설정, 상품, 발주, 발주 명세 |
| 출력 | 발주 알림(전건 삭제 후 생성) |
| 파라미터 | 실행일(생략 시 시스템 날짜) |

처리 내용:
1. 발주 알림을 전건 삭제한다.
2. 상품 창고 설정이 있고 상품·창고가 모두 유효한 「상품 × 창고」에 대해 아래를 구한다.
   - 유효 재고 수 = 현재고 수 − 할당 수(재고 행이 없으면 0)
   - 발주 잔량 = 상태가 「승인 대기·승인 완료·일부 입하」인 발주의 (발주 수량 − 입하 완료 수량) 합계
3. 「유효 재고 수 + 발주 잔량 ≦ 발주점」이고 「발주점 > 0」인 것을 발주 알림에 등록한다.
4. 처리 건수(대상 건수·알림 건수)를 로그에 출력한다.

| 항목 | 내용 |
|---|---|
| 이상 종료 시 | 처리 전체를 롤백(전날 알림이 남음)하고 모니터링에서 개발 담당에게 통지 |
| 재실행 | 그대로 재실행 가능(몇 번 실행해도 결과가 같음) |
| 업무 영향 | 당일 아침 알림이 전날 시점 내용이 된다. 재고 조회 화면에서 발주점 이하 상품을 확인할 수 있어 업무는 계속 가능 |

## 3. BAT-02 월별 재고 집계 배치

| 항목 | 내용 |
|---|---|
| 개요 | 지난달 말 시점 재고 수를 「상품 × 창고」별로 월별 재고에 저장 |
| 입력 | 재고 |
| 출력 | 월별 재고(대상 연월 행을 삭제한 뒤 생성) |
| 파라미터 | 대상 연월(생략 시 실행일의 지난달) |

처리 내용: ① 대상 연월의 월별 재고 삭제 ② 재고 전 행의 현재고 수·할당 수를 대상 연월의 월별 재고로 등록 ③ 처리 건수를 로그에 출력

| 항목 | 내용 |
|---|---|
| 전제 | 월말 영업 종료 후부터 다음 달 1일 영업 시작 전까지 재고가 움직이지 않을 것(운영 시간 외). 배치 실행 시점 재고 수를 월말 재고로 본다 |
| 이상 종료 시 | 처리 전체를 롤백하고 모니터링에서 개발 담당에게 통지 |
| 재실행 | 다음 달 1일 영업 시작(8:00) 전이면 그대로 재실행 가능. 영업 시작 후 재실행하면 당일 입출고가 섞이므로, 그때는 입출고 이력에서 월말 시점 재고 수를 역산하는 절차(운영 절차서에 정함)로 만든다 |

## 4. BAT-03 청구 마감 배치

| 항목 | 내용 |
|---|---|
| 개요 | 지정한 마감일까지의 미청구 출하를 매출처별로 집계해 청구·청구 명세 생성(BR-31~34) |
| 입력 | 출하, 출하 명세, 거래처, 상품, 소비세율 |
| 출력 | 청구, 청구 명세, 출하(청구 ID 설정) |
| 파라미터 | 마감일, 마감일 구분, 매출처 ID(선택), 실행자 사용자 ID |

처리 내용:
1. 대상 매출처(마감일 구분이 일치하고 마감일 이전의 미청구 출하가 있는 매출처)를 가져온다.
2. 매출처마다 아래를 한 트랜잭션으로 처리한다.
   1. 대상 출하(미청구·출하 완료·출하일이 마감일 이전)를 가져온다.
   2. 출하 명세를 세 구분별로 합계해 소비세액을 계산한다(세율별 1회, 1엔 미만 버림).
   3. 청구 번호를 채번하고 청구·청구 명세를 등록한다.
   4. 대상 출하에 청구 ID를 설정한다.
3. 생성 건수를 실행 결과로 기록한다.

마감 대상 조건·계산 방법 상세는 「화면 설계서 SCR-501」 4장·5장 참조.

| 항목 | 내용 |
|---|---|
| 커밋 단위 | 매출처 1곳마다 |
| 이상 종료 시 | 에러가 난 매출처 처리만 롤백하고 배치를 이상 종료로 한다. 처리된 매출처의 청구는 유효 |
| 재실행 | 같은 파라미터로 그대로 재실행 가능. 청구된 출하는 대상에서 빠지므로 처리되지 않은 매출처만 처리된다 |
| 이중 기동 방지 | 실행 중인 청구 마감 배치가 있으면 기동하지 않는다(E-052) |
