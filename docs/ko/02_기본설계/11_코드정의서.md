# 코드 정의서

> ※ 일본어 원본(정본): `docs/ja/02_基本設計/11_コード定義書.md` (1.0판, 2026/12/18)
> 구분값은 프로그램에서 Enum으로 정의한다. 상태 값은 나중에 중간 상태를 넣을 수 있게 10 단위로 둔다.

| 값(상수명) | 일본어 명칭 | 한국어 | 설명 |
|---|---|---|---|
| SALES | 営業担当 | 영업 담당 | 수주 등록, 거래처 관리 |
| WAREHOUSE | 物流担当 | 물류 담당 | 출하, 입하, 발주 등록, 재고 조정, 실사 |
| ACCOUNTING | 経理担当 | 경리 담당 | 청구 마감, 청구서 출력 |
| APPROVER | 承認者 | 승인자 | 발주 승인 |
| ADMIN | システム管理者 | 시스템 관리자 | 사용자 관리, 마스터 관리, 조작 로그 조회, 전 화면 조회 |

## 4. 전표 종류(slip_type·numbering_type) — Enum: SlipType

| 값 | 한국어 | 번호 형식 | 예 |
|---|---|---|---|
| SO | 수주 | SO + YYMM + 연번 4자리 | SO27040001 |
| SH | 출하 | SH + YYMM + 연번 4자리 | SH27040001 |
| PO | 발주 | PO + YYMM + 연번 4자리 | PO27040001 |
| RC | 입하 | RC + YYMM + 연번 4자리 | RC27040001 |
| IV | 청구 | IV + YYMM + 연번 4자리 | IV27040001 |
| AJ | 재고 조정 | AJ + YYMM + 연번 4자리 | AJ27040001 |
| TR | 창고 간 이동 | TR + YYMM + 연번 4자리 | TR27040001 |
| ST | 실사 | ST + YYMM + 연번 4자리 | ST27040001 |
| MG | 이관 | MG + YYMM + 연번 4자리 | MG27040001 |

- YYMM은 전표 날짜(수주일·출하일 등)의 연월. 청구는 마감일의 연월.
- 연번은 종류·연월별로 0001부터. 월 상한 9,999건(성수기 수주 약 1,700건/월에 충분).
- 취소한 전표의 번호는 다시 쓰지 않는다(결번).

## 5. 발주 상태 — Enum: PurchaseOrderStatus

| 값 | 상수명 | 일본어 명칭 | 한국어 | 설명 |
|---|---|---|---|---|
| 10 | DRAFT | 作成中 | 작성 중 | 임시 저장 상태. 편집·승인 신청·취소 가능 |
| 20 | PENDING | 承認待ち | 승인 대기 | 승인자의 승인을 기다리는 상태 |
| 25 | REJECTED | 差戻し | 반려 | 승인자가 반려한 상태. 편집·재신청·취소 가능 |
| 30 | APPROVED | 承認済 | 승인 완료 | 발주서 출력, 입하 등록 가능 |
| 40 | PARTIALLY_RECEIVED | 一部入荷 | 일부 입하 | 일부 수량 입하 완료 |

## 11. 마감일·지급일(closing_day·payment_day)
1~28 = 그 날, 99 = 말일. 29~31은 달에 따라 없으므로 쓰지 않고 말일은 99로 나타낸다.

## 12. 지급 월 구분(payment_month_offset)
0 = 마감일의 당월, 1 = 다음 달, 2 = 다다음 달
