# 메시지 목록

> ※ 일본어 원본(정본): `docs/ja/02_基本設計/07_メッセージ一覧.md` (1.1판, 2026/12/24: E-045, E-046 추가)
> 화면에 실제로 나오는 문구는 일본어(원본)이고, 여기서는 뜻을 한국어로 옮겼다. `{0}` `{1}`은 실행 시 바뀌는 값이다.
> 메시지는 `messages.properties`에 메시지 ID를 키로 정의하고, 프로그램에 문구를 직접 쓰지 않는다.

| ID | 일본어 문구 | 뜻 | 사용처 |
|---|---|---|---|
| I-001 | {0}を登録しました。 | {0}을(를) 등록했습니다 | 각 등록 처리 |
| I-002 | {0}を更新しました。 | {0}을(를) 갱신했습니다 | 각 갱신 처리 |
