## 5. 화면 공통 사양

### 5.1 레이아웃
헤더(시스템명, [메뉴], 사용자명(권한), [로그아웃]) → 경로 표시(예: 재고 관리 > 재고 조회) → 메시지 표시란(정보 = 초록, 경고 = 노랑, 에러 = 빨강) → 각 화면 내용. 그림은 일본어 원본 참조.

### 5.2 공통 규칙

| No | 항목 | 사양 |
|---|---|---|
| 1 | 목록 화면 | 검색 조건 + 검색 결과 구성. 페이지당 50건 페이징(NF-07). 초기 표시에서는 검색하지 않는다(재고 조회·발주 알림 제외) |
| 2 | 정렬 | 전표 목록은 전표 날짜 내림차순, 마스터 목록은 코드 오름차순이 초기값 |
| 3 | 필수 항목 | 라벨에 「※」 표시 |
| 4 | 입력 체크 | 서버 쪽에서 반드시 실시. 에러 시 입력 내용을 유지한 채 같은 화면을 다시 표시하고 항목 아래에 에러 메시지 표시 |
| 5 | 이중 전송 방지 | 등록·갱신 버튼은 누른 뒤 비활성화. 서버 쪽에서도 토큰으로 이중 등록 방지 |
| 6 | 배타 제어 | 전표·마스터 갱신은 낙관적 배타. 다른 사용자가 먼저 갱신했으면 에러(E-020) |
| 7 | 숫자 표시 | 수량·금액은 3자리 구분, 오른쪽 정렬. 금액은 엔 단위(소수 없음) |
| 8 | 날짜 표시·입력 | `yyyy/MM/dd`. 달력에서 선택 가능 |
| 9 | 확인 대화상자 | 취소·승인·반려·확정·마감 처리 실행 전에 표시 |
| 10 | 권한 없는 버튼 | 표시하지 않음(URL을 직접 지정하면 서버 쪽에서 E-012) |
| 11 | 세션 만료 | 로그인 화면으로 이동해 E-013 표시 |
| 12 | 마스터 삭제 | 물리 삭제하지 않고 「무효」로 변경. 무효 마스터는 새 전표에서 선택 불가 |
