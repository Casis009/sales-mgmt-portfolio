# 테이블 정의서

> ※ 일본어 원본(정본): `docs/ja/02_基本設計/10_テーブル定義書.md` (1.0판, 2026/12/18)
> 한국어판은 「키·제약」 열에 PK / NN(NOT NULL) / UQ(일의) / FK / 초기값을 모아 적었다. 자릿수는 형에 함께 적었다.

## 0. 공통 사양

| No | 항목 | 사양 |
|---|---|---|
| 1 | DBMS | PostgreSQL 17, 문자 코드 UTF-8 |
| 2 | 기본 키(ID) | BIGINT, `GENERATED ALWAYS AS IDENTITY` 자동 채번 |
| 3 | 금액 | NUMERIC(소수 없음, 엔 단위) |
| 4 | 구분값 | CHAR(1) 또는 CHAR(2). 값은 「11 코드 정의서」 |
| 5 | 삭제 | 마스터는 물리 삭제하지 않고 `enabled`를 false로. 전표는 취소 상태로 |
| 6 | 외래 키 | 「FK: 참조처」라고 적은 컬럼에는 외래 키 제약을 건다 |
| 7 | 형 방침 | 다른 DBMS 이전을 고려해 PostgreSQL 고유 형(배열, JSONB 등)은 쓰지 않는다 |

### 공통 컬럼
- 공통 컬럼(A): `created_at` 등록 일시, `created_by` 등록자, `updated_at` 갱신 일시, `updated_by` 갱신자(모두 NN). 갱신되는 테이블.
- 공통 컬럼(B): `created_at`, `created_by`만. 추가만 하고 갱신하지 않는 테이블.
- `created_by` / `updated_by`는 사용자 ID. 배치·이관은 0.
- `version`(INT, NN, 초기값 0): 낙관적 배타 제어용. 갱신할 때마다 1 더한다.
