## 3. 이벤트 정의

| No | 이벤트 | 처리 내용 | 이동처 |
|---|---|---|---|
| 1 | 초기 표시 | 지정한 수주의 미출하 명세 표시. 상태가 「수주 완료」「일부 출하」가 아니면 에러(E-021). 출하 창고가 실사 중이면 E-031을 표시하고 출하 등록 버튼 비활성 | — |
| 2 | 출하 등록 클릭 | 4장 체크 후 출하 등록(5장). I-001 | SCR-403 |
| 3 | 돌아가기 클릭 | 입력 내용 파기 | SCR-404 또는 SCR-403 |

## 4. 상관 체크·업무 체크

| No | 체크 내용 | 메시지 |
|---|---|---|
| 1 | 이번 출하 수가 1 이상인 명세가 1행 이상 있을 것 | E-044 |
| 2 | 이번 출하 수가 등록 시점의 잔량(수주 수량 − 출하 완료 수량) 이하일 것 | E-043 |
| 3 | 이번 출하 수가 등록 시점의 현재고 수 이하일 것(BR-03) | E-030 |
| 4 | 출하 창고가 실사 중이 아닐 것(BR-05) | E-031 |
| 5 | 수주 상태가 「수주 완료」 또는 「일부 출하」일 것 | E-021 |
| 6 | 다른 사용자가 먼저 수주를 갱신하지 않았을 것 | E-020 |

※ 2·3번은 화면 표시 후 다른 사용자가 출하·재고 조정을 했을 수 있으므로 등록 시점의 데이터로 판정한다.

## 5. 등록 처리 내용
출하 등록은 아래를 한 트랜잭션으로 처리한다. 도중에 에러가 나면 모두 취소한다.

| No | 처리 | 대상 |
|---|---|---|
| 1 | 출하 번호 채번(SH + 연월(YYMM) + 연번 4자리) | 채번 |
| 2 | 출하·출하 명세 등록(단가·세 구분은 수주 명세에서 이어받음) | 출하, 출하 명세 |
| 3 | 수주 명세의 출하 완료 수량에 이번 출하 수를 더함 | 수주 명세 |
| 4 | 수주 상태 갱신(모든 명세의 잔량이 0: 「출하 완료」, 그 외: 「일부 출하」) | 수주 |
| 5 | 재고의 현재고 수와 할당 수에서 이번 출하 수를 뺌(BR-15) | 재고 |
| 6 | 입출고 이력(구분: 출하) 기록(BR-04) | 입출고 이력 |
| 7 | 조작 로그 기록 | 조작 로그 |

## 6. 보충

| No | 내용 |
|---|---|
| 1 | 출하 내용을 잘못 등록했으면 수주 상세(SCR-403)에서 출하를 취소하고 올바른 내용으로 다시 등록한다(F-406, BR-17). 청구된 출하는 취소할 수 없으므로 청구 마감 전에 출하 내용을 확인하는 운용으로 한다 |
| 2 | 출하일에 과거 날짜를 지정하면 그 출하는 다음 청구 마감 대상이 된다(이미 마감한 기간이어도 미청구 출하로 취급) |
