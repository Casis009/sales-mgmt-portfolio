# 화면 설계서: SCR-303 발주 상세

> ※ 일본어 원본(정본): `docs/ja/02_基本設計/05_画面設計書/SCR-303_発注詳細.md` (1.0판, 2026/12/14). 레이아웃 그림은 원본 참조.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 기능 ID | F-302 발주 승인, F-303 발주서 PDF 출력, F-305 발주 조회 |
| URL | GET /purchase/orders/{id}, POST /purchase/orders/{id}/apply·approve·reject·cancel·close, GET /purchase/orders/{id}/pdf |
| 사용 권한 | 물류 담당, 승인자, 시스템 관리자(조회만) |
| 관련 요건 | BR-22, BR-23, BR-24, BR-25, K-06, K-14 |

## 2. 항목 정의

| No | 항목명 | 종류 | 자릿수 | 필수 | 입력 체크 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 헤더·명세 | 표시 | — | — | — | 발주·발주 명세 내용. 잔량 = 발주 수 − 입하 완료 수 |
| 2 | 승인 이력 | 표시 | — | — | — | 일시 오름차순. 조작(승인 신청·승인·반려), 조작자, 코멘트 |
| 3 | 입하 실적 | 표시 | — | — | — | 입하일 오름차순 |
| 4 | 코멘트 | 텍스트 | 200 | 반려 시만 ○ | 반려 시 필수(E-041), 자릿수(E-002) | 승인자이고 상태가 「승인 대기」일 때만 표시 |

## 3. 버튼 표시 조건

| 버튼 | 표시하는 상태 | 표시하는 권한 | 추가 조건 |
|---|---|---|---|
| 편집 | 작성 중, 반려 | 물 | — |
| 승인 신청 | 작성 중, 반려 | 물 | — |
| 승인 | 승인 대기 | 승 | 신청자 본인이 아닐 것(BR-22) |
| 반려 | 승인 대기 | 승 | 위와 같음 |
| 발주서 출력 | 승인 완료, 일부 입하, 입하 완료 | 물·승 | BR-24 |
| 입하 등록 | 승인 완료, 일부 입하 | 물 | — |
| 취소 | 작성 중, 반려, 승인 완료 | 물 | 승인 완료면 입하 실적이 없을 것 |
| 잔량 취소 | 일부 입하 | 물 | — |

## 4. 이벤트 정의

| No | 이벤트 | 처리 내용 | 이동처 |
|---|---|---|---|
| 1 | 초기 표시 | 발주·명세·승인 이력·입하 실적 표시. 없으면 E-091 | — |
| 2 | 승인 신청 클릭 | 상태를 「승인 대기」로 갱신하고 승인 이력 추가. I-004 | SCR-303 |
| 3 | 승인 클릭 | 신청자 본인이 아님을 확인(E-040)하고 상태를 「승인 완료」로 갱신. 승인자·승인 일시 기록, 승인 이력 추가. I-005 | SCR-303 |
| 4 | 반려 클릭 | 코멘트 입력 확인(E-041) 후 상태를 「반려」로 갱신. 승인 이력 추가. I-006 | SCR-303 |
| 5 | 발주서 출력 클릭 | 발주서 PDF(RPT-02)를 새 탭에 표시. 조작 로그 기록 | — |
| 6 | 입하 등록 클릭 | 입하 등록 화면 표시 | SCR-304 |
| 7 | 취소 클릭 | 상태를 「취소」로 갱신. I-003 | SCR-303 |
| 8 | 잔량 취소 클릭 | 미입하 잔량을 종결하고 상태를 「입하 완료」로 갱신. I-002 | SCR-303 |
| 9 | 편집 클릭 | 발주 등록·편집 화면 표시 | SCR-302 |
| 10 | 돌아가기 클릭 | 발주 목록 표시(검색 조건 유지) | SCR-301 |

## 5. 업무 체크(전 이벤트 공통)

| No | 체크 내용 | 메시지 |
|---|---|---|
| 1 | 조작 시점의 상태가 3장의 표시 조건을 만족할 것(화면 표시 후 다른 사용자가 조작한 경우 포함) | E-021 |
| 2 | 다른 사용자가 먼저 갱신하지 않았을 것 | E-020 |
| 3 | 조작에 필요한 권한이 있을 것 | E-012 |
