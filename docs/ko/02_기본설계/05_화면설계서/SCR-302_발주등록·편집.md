## 3. 이벤트 정의

| No | 이벤트 | 처리 내용 | 이동처 |
|---|---|---|---|
| 1 | 초기 표시(신규) | 빈 명세 5행 표시 | — |
| 2 | 초기 표시(발주 알림에서) | SCR-305에서 고른 상품을 명세에 설정. 입하 창고는 알림의 창고, 매입처는 상품의 주 매입처, 수량은 표준 발주 수량 | — |
| 3 | 초기 표시(편집) | 지정한 발주 표시. 상태가 「작성 중」「반려」가 아니면 에러(E-021) | — |
| 4 | 상품 코드 입력·검색 | 품명·단위·표준 매입 단가·재고 정보 취득 | — |
| 5 | 입하 창고 변경 | 명세의 재고 정보 다시 취득 | — |
| 6 | 행 추가/삭제 | 명세 행 추가/삭제, No와 합계 재계산 | — |
| 7 | 임시 저장 클릭 | 입력 체크 후 상태 「작성 중」으로 등록·갱신. 신규면 발주 번호 채번. I-001/I-002 | SCR-303 |
| 8 | 승인 신청 클릭 | 입력 체크 후 상태 「승인 대기」로 등록·갱신, 신청자·신청 일시 기록. I-004 | SCR-303 |
| 9 | 돌아가기 클릭 | 입력 내용 파기(확인 대화상자) | SCR-301 또는 SCR-303 |

## 4. 상관 체크·업무 체크

| No | 체크 내용 | 메시지 |
|---|---|---|
| 1 | 상품 코드가 입력된 명세가 1행 이상 있을 것(상품 코드가 빈 행은 무시) | E-008 |
| 2 | 같은 상품이 여러 명세에 없을 것 | E-009 |
| 3 | 편집 시 다른 사용자가 먼저 갱신하지 않았을 것 | E-020 |
| 4 | 편집 시 상태가 「작성 중」 또는 「반려」일 것 | E-021 |

## 5. 보충

| No | 내용 |
|---|---|
| 1 | 발주 등록 시점에는 재고 수량이 변하지 않는다. 재고가 느는 것은 입하 등록 때다 |
| 2 | 반려된 발주를 편집해 승인 신청하면 반려 이유는 승인 이력으로 남긴다 |
| 3 | 등록·갱신·승인 신청은 조작 로그에 기록한다 |
