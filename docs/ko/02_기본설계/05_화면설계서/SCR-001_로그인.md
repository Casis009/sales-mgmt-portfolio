# 화면 설계서: SCR-001 로그인

> ※ 일본어 원본(정본): `docs/ja/02_基本設計/05_画面設計書/SCR-001_ログイン.md` (1.0판, 2026/12/11). 레이아웃 그림은 원본 참조.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 기능 ID | F-001 로그인·로그아웃 |
| URL | GET /login(표시), POST /login(인증), POST /logout(로그아웃) |
| 사용 권한 | 미인증 사용자 |
| 관련 요건 | NF-24, NF-25, NF-26, NF-30 |

## 2. 항목 정의

| No | 항목명 | 종류 | 형 | 자릿수 | 필수 | 입력 체크 | 초기값 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 1 | 로그인 ID | 텍스트 | 반각 영숫자 | 4~20 | ○ | 필수(E-001) | 공백 | 앞뒤 공백 제거 |
| 2 | 비밀번호 | 비밀번호 | 반각 영숫자 기호 | 8~64 | ○ | 필수(E-001) | 공백 | 입력 내용은 「●」로 표시. 에러 시 다시 표시하지 않음 |
| 3 | 로그인 | 버튼 | — | — | — | — | — | — |

## 3. 이벤트 정의

| No | 이벤트 | 처리 내용 | 이동처 |
|---|---|---|---|
| 1 | 초기 표시 | 이미 로그인했으면 메뉴로 이동. 세션 만료로 넘어온 경우 E-013 표시 | — |
| 2 | 로그인 클릭(성공) | 로그인 ID와 비밀번호 대조. 인증 실패 횟수를 0으로 되돌리고 최종 로그인 일시 갱신. 조작 로그(로그인 성공) 기록 | SCR-002 |
| 3 | 로그인 클릭(실패) | E-010 표시. 로그인 ID가 있으면 인증 실패 횟수를 1 더하고 5회가 되면 계정 잠금. 조작 로그(로그인 실패) 기록 | SCR-001 |
| 4 | 로그인 클릭(잠금·무효) | 잠금이면 E-011, 무효 사용자면 E-010 표시 | SCR-001 |
| 5 | 로그아웃(헤더) | 세션을 파기하고 조작 로그(로그아웃) 기록 | SCR-001 |

## 4. 보충

| No | 내용 |
|---|---|
| 1 | 로그인 ID가 틀린 경우와 비밀번호가 틀린 경우 같은 메시지(E-010)를 쓴다. 로그인 ID 존재 여부를 추측하지 못하게 하기 위해서다 |
| 2 | 로그인 성공 시 세션 ID를 다시 발급한다(세션 고정 공격 대책) |
| 3 | 초기 비밀번호로 로그인하면 비밀번호 변경 화면(SCR-003)으로 강제 이동한다 |
| 4 | 잠금 해제는 시스템 관리자가 사용자 편집 화면(SCR-012)에서 한다 |
